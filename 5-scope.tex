\section{ขอบเขตของงานวิจัย}
\label{sec:scope}

\begin{enumerate}
    \item แบบประเมินที่ใช้ในงานวิจัยนี้มี 3 ฉบับ ได้แก่ DASH ฉบับภาษาไทย และ TESS ฉบับภาษาไทยสำหรับรยางค์บนและรยางค์ล่าง
    \item ระบบรองรับการสนทนาด้วยเสียงภาษาไทยและภาษาอังกฤษเท่านั้น
    \item งานวิจัยนี้จะใช้โมเดลการรู้จำเสียงพูดและเสียงสังเคราะห์ที่มีอยู่แล้วและไม่ครอบ คลุมการพัฒนาหรือปรับปรุงโมเดลดังกล่าว
    \item โมเดลทั้งหมดเป็นโมเดลที่เปิดเผยค่าน้ำหนัก (open-weight) และประมวลผลบนเซิร์ฟเวอร์ภายใน
    \item การประเมินผลดำเนินการกับผู้ป่วยที่เข้ารับการรักษาในโรงพยาบาลที่ร่วมวิจัย โดยใช้คะแนนจากการสัมภาษณ์โดยพยาบาลเป็นค่าอ้างอิง
    % TODO: ระบุชื่อโรงพยาบาล เกณฑ์คัดเข้า-คัดออก และจำนวนผู้ป่วย
    \item ระบบทำหน้าที่เก็บรวบรวมข้อมูลและให้คะแนนตามแบบประเมินเท่านั้น ไม่ได้ทำหน้าที่วินิจฉัยโรคหรือให้คำแนะนำทางการแพทย์
\end{enumerate}
